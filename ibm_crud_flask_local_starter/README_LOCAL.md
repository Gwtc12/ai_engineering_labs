# Local Flask CRUD Lab Starter

This folder recreates the starter environment needed for the IBM Flask CRUD lab so you can work in VS Code instead of Skills Network.

## Setup

Open this folder in VS Code, then in its terminal run:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

On Windows PowerShell, activation is:

```powershell
.venv\Scripts\Activate.ps1
```

Do **not** fill all TODOs at once. Work through the lab in this order:
1. Initial Flask setup
2. Read
3. Create
4. Update
5. Delete
6. Run and test
